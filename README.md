# CodeXTest

A minimal Python command-line tool that prints a friendly greeting from the CodeXTest project.

## Usage

Run the script directly with Python. Provide a name to personalize the message or omit it for a generic greeting.

```bash
python main.py
python main.py --name Alice
```

## Development

No additional dependencies are required beyond Python 3.10+. The script lives in `main.py` and uses `argparse` for parsing options.
